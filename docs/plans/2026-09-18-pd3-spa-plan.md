Spec: `docs/specs/2026-09-18-pd-teardown-spec.md` v1.2 §3 "P-D.3", §5, §6
"SPA phase". Outline was reviewed with the spec (codex `task-mu6xgcjb-7b7n51`,
findings 2/4/5/6/10 shape this plan); this detailed plan is not sent for a
second plan review. Measured on `cbbd1877` (alpha.396, daemon side of P-D

passes `cd spa && npx tsc --noEmit -p tsconfig.app.json` — **not** the
bare `npx tsc --noEmit`, which is a no-op under the solution-style
`spa/tsconfig.json` (found during T3.2c) — checked per commit before the PR;

`git commit --only`; subagents prefix every Bash with
`cd <worktree>/spa &&`. Real-machine acceptance runs the worktree's own dev

not pulled by this session.
