跨模型 Review：怎麼花更少、抓得更多

前提：Claude Code（Opus 5）主開發，OpenAI Codex CLI（ChatGPT 訂閱）當第二意見；每個 PR 跑 R1 標準 review ＋ R2 三視角 adversarial，spec／plan 各一輪。痛點是配額。這頁回答三件事：現在的流程哪裡在浪費、證據說什麼形態最有效、該不該加第三家模型、加哪家。

本機驗證 我在這台機器實測過的事實 高中低 來源可信度／推論強度 估算 沒有量測、只是推估

00先講結論

🕳️ 現在最大的漏洞：所有 review 都跑在 low effort 本機驗證

plugin 的 handleReviewCommand 只收 base / scope / model / cwd，--effort 只有 task 子指令有。所以 R1、R2 三視角、spec／plan review 全部吃 ~/.codex/config.toml 的 model_reasoning_effort = "low"。社群實測 low 在需要語意判斷的工作上通過率 12%，high 是 38%。我們現在是「低推理 × 很多次」，證據說應該反過來。

📉 R2 三個獨立平行視角，正好落在證據說「最沒增益」的那格 中高

ICML 2026 的 Adversarial Review 論文：reviewer 從 1 → 2 → 5 個 F1 幾乎不動（0.495／0.503／0.501）；三個沒約束的 agent 反而更差（0.457，互相附和）；有效的是「必須引用 file:line 才能反對」（0.533）。Cursor Bugbot 把 8 路平行改成單一 agentic reviewer 後解決率 52% → 70%+。

🧭 該加第三家：DeepSeek V4 Pro（按量、無配額）；第二選 Gemini 3.1 Pro 高

證據支持「2–3 個不同家族各自獨立 review → 主模型仲裁」，超過 3 家沒有 code review 的實證。我們現在是 Claude ＋ OpenAI，補一家就到甜蜜點。DeepSeek 一次 review 約 $0.05–0.5、沒有訂閱配額這件事，正對痛點。

📏 比換模型更有效的：把 diff 切小、加 confidence 門檻 高

diff 大小是召回率最強的預測因子（<10 行 F1 0.657，>150 行 0.043，差 15×）。結構化輸出 ＋ confidence 門檻 ＋ 要求引用是所有主流工具和論文的共同做法，證據最強。adversarial 的 schema 早就有 confidence 0–1，我們只是沒用它過濾。

5模型：spec／plan 與 R1 用 gpt-5.6-sol（純文字推理，可能比 5.5 便宜 20–33%）；gpt-6-astra 只保留給「R2 找到 critical 但兩方互不同意」的仲裁單次呼叫。相對全用 Astra −60%；相對 5.5 可能 −20–33%（促銷期）官方費率表；Bigger-isn't-better中
6縮小 diff：PR 超過 ~800 行或 20 檔就拆；bump／純搬移 PR 跳過 codex review（用逐宣告位元組比對代替）。每次 review 成本與 diff 線性；召回率差 15×2606.15689；ultrareview 8,000 行上限中高
7增量 re-review：修完不重跑整支 branch，--scope working-tree 或 codex review --commit <fix sha>。每次 re-review −50–80%CodeRabbit／REVIEW.md re-review convergence中
8停止條件：R1 無 critical／P1 且 critic 無「有證據的反對」→ ship；第三輪只在第二輪新出現 critical 時。避免第三輪（≈ −25%／PR）AR false-consensus；CCR；既有記憶 feedback_codex_review_termination中高
9加 DeepSeek V4 Pro 當第三家族，複製現有 codex companion 的殼：slash command → script 做 git diff <base>...HEAD → 組 prompt（只回 findings、禁止改碼、指定 JSON schema）→ opencode run --format json 或 ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic claude -p --output-format json。key 進 ~/.config/mcp-tokens.zsh，script 只讀變數名。只送 diff、不送 secret（中國供應商）。每次 $0.05–0.5、無配額；月 100 次不到 $20PoLL 3 家族；c-CRAB 聯集；DeepSeek 官方 Claude Code 整合文件高（能力）中（ANTHROPIC_BASE_URL 那條 Anthropic 端條款未逐字查；保守走 OpenCode）
10外部 reviewer 一律 report-only：Codex 審 Claude 稿是淨負的主因是「整段重寫引入新 bug」。若 companion 允許 review 直接產 patch，關掉；第三家接進來時 prompt 一開始就鎖死。避免 −8.6pp 那種倒退Cross-Model LLM Code Review（2607.21656）中高
11若帳號是 Pro：5 小時限制目前不啟用，review 可集中跑、只管週配額；若是 Plus：R2 排在 5 小時窗口剛重置後。—2026-08-25 政策高（政策）低（持續多久）
