候選 — 四主題同時套用

底色＝色塊底相對於該列背景（看得見方塊嗎，1.00 就是完全隱形）。 內框＝內框顏色相對於該列背景（開了才顯示）。 圖示＝圖示相對於色塊底（圖案讀得出來嗎）。 參考值：底色或內框其中一個 ≥1.15 才看得見輪廓，圖示 ≥3.0 才穩。三個數字都是用 mlab 那台的顏色算的。
這裡有個真實的拉鋸：淺色主題下把底色加濃會讓方塊更明顯，但圖示和底色是同一個色相， 底色越濃圖示就越融進去（底色 100% 時圖示對比會掉到 1.00）。所以淺色靠加厚底色是死路， 要嘛壓低底色改用內框撐輪廓，要嘛線條改中性灰。

對齊（沒有 host 的分頁）

顯示法 B 不額外佔寬度，沒有 host 的分頁本來就對齊 —— 這組開關在 B 之下沒有作用。

Hosts / Settings / editor / browser 這些沒有 tmux pane 的分頁畫不出色塊。 不補位＝標題往左凸出約 22px；補位＝左緣對齊，但那幾列少掉同樣寬度的標題空間。 建議側欄補、上方不補：側欄是垂直清單，參差最明顯；上方有固定寬度與分隔線，看不太出來且空間更擠。
